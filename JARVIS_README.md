# 🤖 JARVIS -- AI Assistant

> *Every intelligent system begins as an experiment.*\
> JARVIS is a browser-based AI assistant inspired by the MCU's JARVIS.
> It provides conversational AI, built-in commands, persistent chat
> memory, and a clean mobile-friendly interface.

------------------------------------------------------------------------

# 📖 About

JARVIS was built as a personal AI assistant to explore conversational
interfaces, prompt engineering, browser storage, and AI API integration.

Unlike a simple chatbot, JARVIS maintains conversation history using
LocalStorage, supports built-in commands, and keeps an Iron Man inspired
personality throughout every conversation.

This project became the foundation for later AI experiments and helped
shape future assistants developed by the author.

# 🔄 Working Principle

1.  User enters a prompt.
2.  Message is added to conversation memory.
3.  Request is sent to the AI API.
4.  AI response is displayed.
5.  Conversation is stored locally.
6.  Previous chats are restored automatically when reopened.
